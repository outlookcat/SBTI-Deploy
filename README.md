# 🚀 SBTI-Deploy：一键部署 SBTI 人格测试

本仓库是 SBTI 人格测试系统的极速部署版本。支持通过 Cloudflare Pages 实现**秒级上线、全球加速、永不掉线**。

---

### 🛠️ 3步极简部署指南（完全免费）

#### 1. Fork 本仓库
点击页面右上角的 **Fork** 按钮，将项目复制到你自己的 GitHub 账号下。

#### 2. 授权 Cloudflare
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 点击左侧菜单的 **Workers 和 Pages** -> **创建应用程序** -> **Pages** -> **连接到 Git**。
3. 选择你刚才 Fork 的 `SBTI-Deploy` 仓库。

#### 3. 确认上线
在“构建设置”页面直接点击 **保存并部署**（无需修改任何参数）。
> **构建命令**: 留空  
> **输出目录**: `.`

**恭喜！你现在已经拥有了一个专属的 SBTI 测试网站链接。**

---

### 🌟 为什么选择这个版本？
- **零成本**：无需购买服务器，无需购买域名。
- **自动同步**：当你修改 GitHub 里的 HTML 内容时，网站会自动更新。
- **SEO 优化**：预设了搜索权重配置，更容易被搜到。
